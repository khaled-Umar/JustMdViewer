#A Markdown viewer that only views.

JustMdViewer opens .md files in tabs, in a clean, GitHub-style reading view on Windows. No editor, no account, no telemetry. The installer is 2.8 MB.

##What it does

It shows Markdown the way GitHub does and stays out of the way. There is nothing to configure before the first file opens.

###Renders what you write

  • | a | b |
    Tables

    Aligned columns, header rows and borders, as on GitHub.

  • - [x]
    Task lists

    Checked and open items render as checkboxes.

  • ```cs
    Highlighted code

    Syntax colouring, plus a Copy button on every code block.

  • [^1]
    Footnotes

    Numbered references with the notes collected at the end.

  • :tada:
    Emoji

    Shortcodes turn into emoji.

  • ![](./img.png)
    Local images

    Relative paths resolve next to the file you opened.

###Made for reading

  • Ctrl+Tab
    Tabs

    Every file opens in its own tab in one window. Ctrl+1…9 jumps to a tab, Ctrl+W closes one.

  • Session
    Back where you left off

    Your tabs reopen the next time you start the app, each with its scroll position and outline as you left them.

  • Open with
    One window

    Double-click a file, use the right-click menu, or drop files on the window. If the app is already open, the file joins it as a new tab.

  • Ctrl+Shift+O
    Outline

    A collapsible tree of the headings. Hide it and bring it back without losing which branches were open.

  • [text](url)
    Links you can check

    Web links show the full address in a warning first, then open in your browser. Links to other Markdown files open in a new tab.

  • F5
    Auto-reload

    Save the file in your editor and the view updates. F5 reloads by hand.

  • Ctrl+T
    Themes

    Switches between System, Light and Dark. The same toggle sits in the header.

  • Ctrl+F
    Find

    Search the text of the document.

  • Ctrl +/−/0
    Zoom

    Make the text bigger or smaller, or reset it.

  • Ctrl+P
    Print

    Print the document as it is rendered, or save it as PDF.

##Install

One 2.8 MB installer. Install it for yourself, or for everyone on the PC.

  1. Download the installer

    Get JustMdViewer-Setup-1.0.0.exe from the latest release.

  2. Run it

    The installer isn't code-signed yet, so Windows SmartScreen may warn you. Choose More info, then Run anyway.

  3. Choose who it's for

    It installs just for you by default. You can choose to install for all users instead.

  4. Pick the options

    Associate Markdown files with JustMdViewer and Add 'Open with JustMdViewer' to the right-click menu are ticked; a desktop shortcut is not. On Windows 11 the right-click entry is under Show more options.

  5. Confirm the default app once

    If another app already opens .md files, Windows keeps it and may ask once which app to use. Pick JustMdViewer and choose Always, or change it in Settings › Apps › Default apps.

Requirements

  • Windows 10 or 11, 64-bit. The app is an x64 build; on Arm PCs it runs through Windows' x64 emulation.
  • .NET 10 Desktop Runtime (x64), also on Arm PCs. If it's missing, the installer tells you and offers Microsoft's download page.
  • WebView2 Runtime. Already on Windows 11 and most Windows 10 PCs. The installer warns you if it's missing.

##Security and privacy

A Markdown file can come from anywhere, so JustMdViewer treats every document as untrusted.

  • Documents can't run code

    Embedded HTML is sanitized, and a strict Content Security Policy blocks scripts. Nothing in a file executes.

  • No link opens silently

    You see the website and the full address before your browser opens it, with a warning for look-alike international names and for user@host tricks.

  • No telemetry, no accounts

    The app sends nothing anywhere. The only network requests come from images a document links to by URL.
